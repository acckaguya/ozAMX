# V4 AMX load-schedule experiment source kit

This isolated tree starts from the frozen V3 release source. It adds the compile-time selector `OZV4_LOAD_GROUP` (0: V3 baseline, 1: column-group, 2: row-group); the frozen `OZAMX_LOAD_SCHEDULE` tuning knob remains unchanged. The assembly variants are pending root-authored implementation. No build or benchmark has been run from this tree. This is an experiment, not a production release. See `SOURCE_ORIGIN.json` and `SOURCE_IDENTITY.json` for provenance.
